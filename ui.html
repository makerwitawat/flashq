วิธีอ่านภาพ

  • 🧑‍💻 นั่งโต๊ะ = งานกำลังทำ (เลขช่องอยู่ที่โต๊ะ) · โต๊ะว่าง = ยังไม่มีงาน
  • 🎨 สีเสื้อ = โปรเจกต์ (โปรเจกต์เดียวกันสีเดียวกัน)
  • 🔍 ใส่แว่น + ถือแว่นขยาย = ผู้ตรวจ (verify · อ่านอย่างเดียว ไม่ชนงานอื่น) · ป้ายหน้างานเขียนว่า "ตรวจ"
  • 🛋 ห้องพัก (แถบล่างสุด) = โซฟา 4 ที่นั่งของ ผู้ตรวจ · ยาม · นักทดสอบ · ช่างเอกสาร · ไม่มีงาน = นั่งพักที่โซฟา · ว่างเกิน 10 นาที = หลับ 💤 · ไปทำงาน = เบาะว่างเขียน "ไปทำงาน" (เวลาว่างนับจากที่เปิดหน้านี้ ถ้าไม่เคยเห็นมีงาน)
  • 🚶 ผู้ตรวจประจำออฟฟิศ (แถบม่วงใต้โต๊ะ) = มีงานตรวจรันอยู่จะยืนประจำและบอกช่องที่กำลังตรวจ · ว่างจะไปนั่งที่โซฟา · 🧪 นักทดสอบ เสื้อกาวน์เขียวมิ้นต์ถือขวดทดลอง · 📝 ช่างเอกสาร เสื้อกันเปื้อนสีทรายถือคลิปบอร์ด+ดินสอ นั่งโต๊ะตอนมีงาน
  • 🛡 ยามเฝ้า shell (ชุดกรมท่า หมวกยาม ถือไฟฉาย) = มีคำสั่ง shell รันอยู่จะยืนเฝ้าที่ช่องนั้น ว่างจะไปนั่งที่โซฟา · ❗ = โปรเซสนิ่ง (CPU/I/O ไม่ขยับ) · 🚨 จับได้ = ฆ่าคำสั่งค้างแล้ว งานทำต่อ (ไม่ฆ่าทั้งงาน) · เฉพาะ Windows + --attach server
  • 🚩 เป้าหมาย (/flash-goal) = ธงที่โต๊ะ "รอบ 2/5" = งานนั้นเป็นรอบหนึ่งของเป้าหมาย · เสาธง (แถบล่างสุด) ธงขึ้นสูงตามจำนวนเกณฑ์ที่ผ่าน · ผ่านครบ = ธงเขียวโบก+ฉลอง · รอคุณตรวจ = ธงเหลือง 👀 · หยุดเพราะเบรก = ธงแดงครึ่งเสา · แจ้งเตือน/เสียงเมื่อผ่าน/หยุด/รอตรวจ
  • 🏢 ห้องทำงาน = พื้นไม้ ผนัง หน้าต่าง+ม่าน ชั้นหนังสือ ไวท์บอร์ด รูปภาพ ตู้น้ำ ต้นไม้ · โต๊ะมีคีย์บอร์ด เมาส์ แก้วกาแฟ เอกสาร ไฟสถานะจอ เก้าอี้มีล้อ (ตกแต่งอย่างเดียว ไม่มีผลกับสถานะงาน)
  • 👔 แต่งตัวต่างจากคนงาน = ผู้ตรวจใส่เสื้อกาวน์ขาว+เนคไท+แว่น · 🕵️ ผู้สืบ (flash-investigator) ใส่โค้ทเบจ+หมวกนักสืบ · ทั้งคู่ถือแว่นขยาย
  • 🧑‍⚖️ Claude กำลังตรวจ = ป้ายจาก /flash-check (flashq review) · ผ่านชูมือ · ไม่ผ่านหน้าเสีย + แจ้งเตือน/เสียง · มือถือเลื่อนฉากแนวนอนได้
  • 🧍 ยืนต่อแถวด้านซ้าย = งานรอคิว (#1 = ถัดไป · ไอคอนข้างเลข 🔍🕵️🧪📝 = ชนิดงาน) · ถือป้าย ⏸ = ยังไม่เริ่มเพราะชนไฟล์/แผนสั่งให้รอ
  • 📊 แถบใต้โต๊ะ = ความคืบหน้าโดยประมาณ (เทียบกับเวลาที่เคยใช้ + งาน T-xx ที่ commit แล้ว) · แถบเลื่อน = ยังประมาณไม่ได้
  • 🎉 ชูมือ = จบ OK · 😢 ก้มหน้า = FAIL/TIMEOUT/NOSTART · 🚫 = DENIED (opencode ปฏิเสธสิทธิ์ งานไม่ได้ทำ — ดูทางแก้ในกล่อง log) · ☕ ถือกาแฟ = QUOTA (โควตาหมด) — แสดงที่โต๊ะเดิม ~20 วินาที แล้วเป็นโต๊ะว่าง
  • 😴 นอนที่เก้าอี้มุมซ้ายล่าง ("⚠ process ตาย") = งานที่ process ตาย (ดูแผงเตือนในแดชบอร์ด) · ไม่เกี่ยวกับโซฟาห้องพัก
  • ⏱ ทุก เวลาที่ประมาณ มาจากประวัติงานที่ผ่านมา (ค่ากลางต่อ T-xx) ไม่ใช่ค่ารับประกัน — คิวจริงอาจเร็ว/ช้ากว่านี้ได้
